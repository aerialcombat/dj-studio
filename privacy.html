Privacy policy

Last updated 30 October 2026.

DJ Studio is a private tool that uploads its owner's videos to the owner's own YouTube channels. It is used only by its owner.

Data it accesses

When a channel is signed in, DJ Studio receives an access token from Google for the YouTube Data API. With it, DJ Studio reads the channel's name and ID and uploads and schedules videos on that channel. It does not read viewers' data, comments, messages, or any other Google account data.

Where data is kept

Sign-in tokens are stored only on the owner's own computer, in a file readable only by the owner. A log of uploaded videos (title, video ID, time) is kept on the same computer.

Sharing

DJ Studio does not sell, share or transfer any data to anyone. Data is sent only to Google, as part of the YouTube API calls described above.

Google API Services

DJ Studio uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy. DJ Studio's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Removing it stops all uploads. The owner can also delete the stored tokens from the computer.
